## 📌 О проекте
**PMS** — это веб-приложение, которое помогает командам эффективно организовывать работу, распределять задачи и отслеживать прогресс проектов.  

🔹 **Основные возможности:**  
✔️ Создание и управление проектами  
✔️ Распределение задач между участниками  
✔️ Отслеживание статусов выполнения  
✔️ Удобный интерфейс для командной работы

## ⚙️ Технологии
### **Backend**
